# Разработка интернет-приложений (РИП) 2025
## Расчет бюджета создания постройки/произведения с учетом исторического индекса цен
Разработанное приложение позволит исследователям создавать и формировать сметы на расчёты бюджета создания постройки/произведения с учетом исторического индекса цен, а профессорам завершать или отклонять данные заявки.
